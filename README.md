# Dotfiles

This repository contains a reproducible setup for my macOS development environment. It includes configuration files, command-line utilities, and application setup scripts designed to streamline system initialization on a new machine.

## Setup

To install and configure this environment on a fresh macOS system, run the following command:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/imAliAzhar/dotfiles/macos/scripts/bootstrap.sh)"
```

This command downloads and runs the bootstrap script, which will automatically clone the repository, install required tools, and configure your system using the provided dotfiles.
